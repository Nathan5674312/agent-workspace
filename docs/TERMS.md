# Terms of Service — not applicable yet

**There is deliberately no terms-of-service document here, and adding one now
would be theatre.**

Terms of service are a contract between a service operator and a user. This app
is a single-user desktop program that runs on its owner's machine and talks to a
server on that same machine. There is no operator, no user other than the owner,
no account, no hosted service, and therefore no counterparty. A document that
purports to bind someone to terms, where there is nobody on the other side, is
decoration rather than a legal instrument.

## When this stops being true

Write real terms — with a lawyer, not with an agent — if any of these happen:

- The app is distributed to anyone else, packaged or as source.
- It gains a hosted component: sync, an account, a shared vault, a server you run.
- It processes anyone's data but your own.
- Money is involved in any direction.

## What matters before then

Two things that are real today and are covered elsewhere:

- **`LICENSE`** — the terms under which the *code* may be used. This one is a
  genuine gap for a repository and needs a decision.
- **[`ARTWORK.md`](ARTWORK.md)** — permission for a third party's original work
  that is committed to this repository. This is the one with an actual person's
  rights attached, and it has open questions.
