licensed and all require their copyright notice to be preserved in
distributions — which is what this file is for.

| Package | Licence | Role |
|---|---|---|
| electron | MIT | Desktop runtime |
| react, react-dom | MIT | UI |
| d3-force | ISC | Graph layout simulation |
| lucide-react | ISC | Icon set |
| vite, electron-vite, @vitejs/plugin-react | MIT | Build (dev only) |
| typescript | Apache-2.0 | Build (dev only) |

Full licence texts are in each package's directory under `node_modules/`.
Regenerate an exhaustive list at any time with `npx license-checker --summary`.
